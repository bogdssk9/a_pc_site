# Angel PC — контекст проекта
Дата передачи: 16.09.2026.

## Задача
Редизайн страницы магазина игровых компьютеров Angel PC. Исходная страница размещена на Яндекс Бизнесе. Пользователь запросил готовый сайт с кодом, затем визуальный референс, затем юридические материалы и передачу всей информации файлами.

## Исходные ссылки
- Страница: https://angel-pc.clients.site/
- Avito: https://www.avito.ru/brands/angelpc/all/nastolnye_kompyutery?sellerId=97b6c66aadd1e3c1144c07949cf78a86
- Telegram-канал: https://telegram.me/ANGELPC_msk
- Telegram-бот: https://t.me/ANGELPC_msk_bot

## Решения, принятые в переписке
1. Новый дизайн: графитовый фон, белая типографика, оранжевые акценты, премиальный технологичный характер без перегруженного RGB.
2. Нужен сайт с кодом, а не только макет.
3. Для первой версии согласованы демонстрационные сборки: реальные объявления, цены и фотографии не предоставлены.
4. Визуальный референс был создан как изображение в переписке.
5. От удаления фона у референса пользователь отказался: сохранить результат.
6. Затем был передан одностраничный HTML-код с каталогом, подбором и переходами в Telegram/Avito.
7. Под «коммерческими и юридическими операциями» пользователь уточнил cookies, политику и соглашения. Регистрация бизнеса, заключение договоров и подключение платежей не входят в подтверждённый объём этих дополнений.
8. Пользователь прямо указал: Яндекс Метрики не будет.
9. Юридические документы подготовлены как проекты, поскольку полные реквизиты и фактическая инфраструктура отсутствуют.

## Что представляет собой передача
Исходный HTML из переписки перенесён в файловый проект, стили и скрипты вынесены в отдельные файлы. Юридические страницы подключены. Это адаптация ранее переданного кода, а не точная копия картинки-референса. Добавлены доступные без JavaScript ссылки на документы, экранирование текстовых полей каталога и сообщение для отключённого JavaScript.

## Изображения
Файл созданного референса в текущей рабочей папке недоступен, поэтому он не вложен в архив. Его нельзя считать исходником вёрстки. Предыдущая картинка остаётся в чате. Новой генерации и подмены референса при передаче не было.
Фон в коде ссылается на изображение исходного сайта. Фотографии отдельных системных блоков отсутствуют; в карточках используются типографические обложки.
