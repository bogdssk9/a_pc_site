# Устройство сайта и пользовательские сценарии

## Стек
Статический HTML5, CSS3, обычный JavaScript. Без React, npm, сборщика, сервера приложения и базы данных. Для локального открытия достаточно браузера. Для HTTP-просмотра можно использовать встроенный сервер Python. Внешние библиотеки не требуются.

## Файлы
- site/index.html — структура, навигация, подбор, контакты, диалог и ссылки на документы.
- site/styles.css — тема, сетки, адаптивность, фон.
- site/app.js — демонстрационные данные, фильтрация, подбор и копирование.
- site/legal/legal.js — оформление юридических ссылок и информационное уведомление.
- site/legal/privacy.html — проект политики.
- site/legal/terms.html — проект соглашения.
- site/legal/cookies.html — информация о cookies.

## Каталог
Массив products в app.js содержит три объекта с id, name, tier, category, description и specs. Данные встроены в код; JSON-файл в документации служит справкой и автоматически не загружается.
Фильтр «Все ПК» показывает 3 карточки; «Для игр» — 3; «Для работы» — PRO и ULTRA. «Подробнее» открывает нативный dialog, характеристики и редактируемое обращение.

## Алгоритм подбора
Бюджет 50 000–350 000 ₽, шаг 10 000 ₽, начальное значение 150 000 ₽.
- Ниже 120 000 ₽: START для игр; индивидуальный подбор для работы и смешанного сценария.
- От 120 000 до 229 999 ₽: PRO.
- От 230 000 ₽: ULTRA.
Это условные границы демонстрации интерфейса, не исследованные рыночные цены и не расчёт стоимости. Алгоритм не проверяет игры, разрешение, совместимость, доступность комплектующих или FPS.
Изменение бюджета или задачи очищает прошлый результат.

## Обращение
Посетитель выбирает вариант → открывает диалог → дополняет текст → копирует → самостоятельно открывает Telegram → вставляет и отправляет текст.
Кнопка открытия Telegram не передаёт текст автоматически. Сайт не подтверждает доставку заявки и не сохраняет обращения. Нет интеграции с API бота.
Clipboard API используется по нажатию. При недоступности доступно ручное копирование выделенного текста.

## Cookies
Скрипты не создают cookies и не используют localStorage/sessionStorage. Кнопка «Понятно» скрывает уведомление до перезагрузки без сохранения выбора. Ссылки на документы остаются доступны в подвале и при отключённом JavaScript. Уведомление расположено в потоке страницы, не фиксировано поверх контента.

## Данные и внешние запросы
Бюджет и задачи → память вкладки.
Текст обращения → память вкладки → буфер обмена по клику.
Фоновое изображение → запрос браузера к avatars.mds.yandex.net.
Клик Telegram/Avito → внешняя страница.
Загрузка сайта → запрос к будущему хостингу; его логи/cookies пока неизвестны.
Автоматической отправки заявки, аналитики и рекламных запросов код не содержит.
