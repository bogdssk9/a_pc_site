# Angel PC — полный пакет передачи

Откройте `site/index.html` для просмотра сайта. Код и юридические страницы уже связаны; установщик не требуется.

## Состав
- `site/` — исходники статического сайта: HTML, CSS, JavaScript и юридический модуль.
- `docs/01-project-context.md` — контекст, решения и источники.
- `docs/02-architecture-and-flows.md` — устройство и сценарии.
- `docs/03-content-and-design.md` — визуал, контакты и отличия от референса.
- `docs/04-legal-status.md` — статус документов и недостающие сведения.
- `docs/05-launch-and-handover.md` — запуск, размещение и следующие этапы.
- `docs/07-step-by-step-technical.md` — пошаговая техническая инструкция от распаковки до домена и HTTPS.
- `docs/06-verification.md` — фактически выполненные проверки.
- `docs/catalog-demo.json` — справочная копия данных каталога.
- `docs/operator-fields.json` — поля, которые необходимо заполнить.
- `MANIFEST.sha256` — контрольные суммы файлов.

Это первая статическая версия с демонстрационными сборками, не опубликованный интернет-магазин. Реальных цен/фото товаров, серверного приёма заявок и платежей нет. Юридические документы содержат поля для заполнения. Метрика не подключена.

Визуальный референс был показан в чате; доступного исходного изображения в архиве нет. HTML не является его точной копией.
